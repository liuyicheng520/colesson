高等数学：函数、极限与连续精读

智学体学习导读 · 基础 · 约 18 分钟

从函数概念出发，理解极限的“无限逼近”语言，并弄清连续与可导的差别。

阅读正文

学习「高等数学」时，先把函数看成“输入到输出的对应规则”，关注定义域与对应方式。极限描述当自变量趋近某值（或无穷）时，函数值能否稳定逼近某个数；ε-N / ε-δ 语言只是把“任意接近”写精确。连续要求极限存在且等于函数值；可导更强，还要求割线斜率有极限。建议用 y=|x| 在 0 点：连续但不可导，帮助区分三个层次。每学一个定义，立刻配一个会算的例子和一个反例，比只背文字更有效。

高等数学极限连续

阅读要点

函数先明确定义域与对应规则

极限是逼近，不等于函数值本身

连续 ⊂ 有极限；可导 ⇒ 连续，反之不然

建议阅读

书籍高等数学（同济版）上册 — 同济大学数学系：国内主流教材，极限与连续章节例题充分。

书籍Thomas' Calculus（托马斯微积分）相关章节 — Hass / Heil / Weir：几何直观强，适合建立极限直觉。

高等数学：导数与积分的对应关系

智学体学习导读 · 进阶 · 约 20 分钟

导数刻画瞬时变化率，积分刻画累积；微积分基本定理把两者连起来。

阅读正文

导数是割线斜率的极限，对应瞬时速度、边际成本等变化率问题。定积分是分割—近似—取极限的累积过程；不定积分是求原函数。微积分基本定理说明：求导与积分在一定条件下互为逆运算。做题时先问：题目在求变化率还是求总量？再选择微分或积分工具。常见陷阱：忽视定义域、复合函数链式法则漏乘内层导数、换元后忘改上下限。建议准备一张对照表：左侧写应用场景，右侧标注该用导数还是积分，并各配一道课本例题。

高等数学导数积分

阅读要点

导数=瞬时变化率

定积分=累积量

基本定理连接求导与积分

建议阅读

书籍高等数学（同济版）导数与积分章 — 同济大学数学系：计算训练完整，适合考试与作业。

书籍Calculus Made Easy（选读） — Silvanus P. Thompson：用更口语的方式建立微积分直觉。

课程可汗学院 Calculus — Khan Academy：短视频拆解求导积分步骤，适合查漏补缺。
