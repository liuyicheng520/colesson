# 答辩补充材料：质量保障与功能闭环

> 与《答辩文稿_八章节》配套使用。本文档覆盖文稿定稿后完成的一轮系统性质量工程与功能收尾，答辩时可作为"项目完善度"的量化论据。

## 一、质量保障体系（可量化）

### 1. 安全加固（20+ 项，重点列举）

| 类别 | 措施 |
|---|---|
| 认证与会话 | 改密后全局撤销会话；登录/注册按 IP 限流（10 次/分）；临时密码不再落盘 |
| 越权防护 | 智能体协作写入校验任务归属；KB 重建索引收敛到管理员；附件按班级归属访问控制 |
| 输入安全 | 附件扩展名白名单（拦截 exe/html/svg 等）；Content-Disposition 按类型强制（防内联渲染） |
| 注入面 | 匿名接口（track/judge）按 IP+guestId 限流 |
| 供应链 | python-jose → PyJWT（CVE 修复）；去掉前端全部第三方 CDN 依赖（11 个文件），消除供应链与可用性风险 |
| 密钥治理 | 服务端启动拒绝源码默认 JWT 密钥；宿主↔学生端桥接改共享密钥头（X-Host-Secret） |

### 2. 数据完整性

- 项目存储改**原子写**（临时文件 + ATOMIC_MOVE），杜绝并发写损坏
- 损坏文件自动备份（`.corrupt_时间戳`），不再静默清空
- 删除项目联动清理班级绑定，消除悬挂引用

### 3. 展示诚实性（面向评审可验证）

- 统计口径修正：基线为零时环比显示"暂无"（不伪造 +100%）；无测验数据时正确率显示"暂无"
- 演示模式内容全部带**明显水印**（"⚠️ 演示模式：本地模板生成，非 AI 输出"），评审可直接区分真实 AI 与本地回退
- 运营看板报告缺失时明确报错降级，不造假数据

### 4. 全端回归基线

- **43 个页面**（教师多页 10 + 学生 SPA 15 + 管理 SPA 18）状态码全绿
- 6 条核心接口链路（智能体配置保存/系统设置保存/知识库检索/资源生成/桥接登录/权限隔离）全部通过
- 真实浏览器 375×812 视口逐页测量：**学生端 9 页、管理端 14 页、教师端 8 页横向溢出全部为 0**

## 二、功能闭环补全（本轮新增）

### 1. 智能体配置真实保存（原来是演示假保存）

- 后端新增 `PUT /agents/definitions/{code}`（仅管理员，越权 403，字段校验 422）
- 管理员可见停用项，消除"停用后无法再启用"死角
- 前端编辑弹窗：名称/描述/模型/Prompt 模板（留空不覆盖）/启用状态

### 2. 实战演练自测闭环（原来学生无法作答）

- 每题「我的作答」草稿（localStorage 按资源+题号持久化，刷新不丢）
- 主动「对照参考答案」→ 自评（已掌握/需再练）→ 进度条 x/y → 单项重置
- 真浏览器 E2E：作答 → 揭示 → 自评 → **刷新恢复** 全部验证通过

### 3. 非编程实战资源生成缺口修复

- 问题：编程/数学有模板兜底，通用学科解析失败时生成空壳资源
- 修复：mock 三学科结构化分支（数学四题带步骤 / 英语三类 / 通用三题带答案）+ 通用模板兜底（保留原始输出摘要，诚实可溯）

### 4. 工程链路

- SPA 构建同步脚本 node 原生崩溃（exit 127）根因定位，改 Python 同步，`npm run build` 一条命令直达可用
- `/admin/system` 旧路径 302 兜底，消除 Whitelabel 错误页

## 三、部署工程（答辩可演示"一键上线"）

- 单 JAR 架构：宿主启动自动拉起 FastAPI（venv 探测，Linux/Windows 兼容），浏览器只访问 8082
- 部署套件：打包脚本 → systemd 单元 → 服务器一键安装 → 线上冒烟验证，四步可重复执行
- 知识库随包分发（26MB 向量索引），新机部署免重建

## 四、答辩问答弹药（预判追问）

**Q1：演示现场没配 AI Key 会怎样？**
A：全链路有 mock 提供商兜底，8 个智能体全部有结构化模板输出且带演示水印，功能流程完整可演示；配置 Key 后同一管线输出真实 AI 内容。

**Q2：怎么保证多用户数据安全？**
A：三层——认证层（会话撤销/限流）、授权层（任务归属/班级归属/角色校验）、传输层（桥接共享密钥）；附件白名单 + 强制下载防挂马。

**Q3：检索增强（RAG）怎么证明真的在工作？**
A：知识库 2389 个向量块，检索命中返回带来源引用（文档名+片段+得分），资源生成与智能答疑的回复可展示引用溯源。

**Q4：移动端适配到什么程度？**
A：三端 31 页在 375px 真实视口逐页测量，横向溢出为 0；管理端小屏自动折叠侧栏、头部收纳，弹窗全局 max-width 兜底。

**Q5：数据会不会丢？**
A：关键存储原子写 + 损坏自动备份；删除操作联动清理；全程 SQLite/MySQL + JSON 双轨，可平滑迁移。

**Q6：项目的创新点在工程上如何落地？**
A：8-Agent 流水线（SSE 实时进度）、画像驱动生成约束、三级 embedding 降级（Qwen→bge→hash 离线兜底）、单 JAR 双后端架构——分别对应"协同生成、千人千面、离线可用、部署简单"四个可讲的故事。
