## 分步脚本

### Step 1 · 开场：痛点与三端入口（0.5min）

打开 **`/login.html`**（统一认证中心）。
话术：*"老师的痛点是备课慢、学情看不见；学生的痛点是资源不对路。智课共生用一套账号体系连接三个身份空间——教师、学生、管理。"*
指一下三张入口卡片即可，不登录，直接跳到教师入口。

### Step 2 · 教师备课链路（1.5min）

登录教师账号 → **`/workspace.html`**。
1. 上传一份 PPT（已备好：`docs/答辩/demo材料/qa_fixture.pptx`，答辩前拷到桌面）
2. 点「解析」→ 讲文稿区出现文本；点「生成讲稿」→ 讲稿生成（若现场未配 Key，指水印说明：*"这是本地模板兜底，配 Key 后同一条管线输出真实 AI 内容——三级降级保证离线可用"*）
3. 点「保存为智课」→ 得到一个项目

### Step 3 · 班级发布链路（1min）

进 **`/classes.html`** → 打开 **QA测试班**（11 名学生、邀请码 WLDZ8H）。
- 「发给本班上课」：选中刚才的智课发布
- 「布置作业」：已有一份《机器学习核心概念练习》（2 份提交）可现场展示
- 公告已发（"欢迎使用智课共生"）

### Step 4 · 学生端学习链路（2min）★重点

新开浏览器隐身窗口（避免会话串）→ **`/student/login.html`** → 登录 `stu01 / Demo2026`。
1. **`/student`**：学习工作台（画像/资源/路径/回看四步链路图 + 班级智课入口）
2. **`/student/course-center`**：课程中心看到老师发的智课
3. **`/student/resources/square`**：资源广场 → 点右上角**知识图谱**按钮（可视化亮点）
4. **实战演练自测**：在资源广场点开「TCP 与 UDP 的区别 - 实战演练」卡片（公开资源，注意链接带 `scope=public`；直达地址 `/student/resources/31?scope=public`）——现场打字写答案 → 点「对照参考答案」→ 自评「已掌握」→ 指进度条 1/3；刷新页面证明**草稿不丢**
5. **`/student/tutor`**：智能答疑，问一个 TCP 相关问题，指**引用来源**（知识库溯源）

### Step 5 · RAG 检索证据（1min）

回到答疑页或讲稿生成页，话术：*"刚才回答的每一句都能给出来源——本地知识库 2389 个向量块，问答评测 20 样本数据集命中率 100%。"*（备用数字见下）

### Step 6 · 多智能体流水线（1min）

隐身窗口登管理员 → **`/admin/agents`**。
- 14 个智能体定义、可编辑配置（改个模型点保存，证明**真实落库**）
- 指生成任务：8-Agent 编排（学情分析 → 讲义 → 习题 → 拓展 → 代码 → 审核…），SSE 实时进度

### Step 7 · 成果验收（1min）

**`/admin/dashboard`**：平台数据大盘（用户数、学习时长、趋势图）。
备用硬数字（真实评测报告，可现场打开 JSON）：
- 解析基准：**101 份课件样本，成功率 100%**，P50 延迟 158ms / P90 600ms（`/reports/evaluation/parse_benchmark_report_full.json`）
- 问答评测：成功率 **100%**、数据集命中率 **100%**（`/reports/evaluation/eval_answer_question_report.json`）
- 样本库：7 个来源 / 81 个课件 / 546MB（`/reports/samples/sample_inventory.json`）

### 收尾（30s）

回到 `/login.html`。话术：*"一条链路走完：备课快了、资源对路了、学情看得见了。这就是智课共生。"*

## 风险预案

| 风险 | 预案 |
|---|---|
| 现场 AI Key 不可用 | 全链路 mock 兜底 + 水印明示，流程不中断（本身就是三级降级设计的卖点） |
| 学生端登录态串号 | 学生演示一律用隐身窗口；教师/管理员用普通窗口 |
| 数据被清理脚本误删 | 演示前跑一遍 Step 4 确认 QA班智课与资源 31 存在 |
| 断网 | 本地演示全套可离线（mock + 本地知识库 + 本地向量检索） |
| 评委追问安全 | 见《答辩补充_质量保障与功能闭环.md》问答弹药 Q1-Q6 |
