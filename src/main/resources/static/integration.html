场景适配说明

系统以课程页为主要挂载位置，教师可在课程建设或资源管理场景中进入智课工作台，完成课件解析、讲稿生成、智能问答和数字人资源制作。学生则通过课程资源入口进入学生学习界面，围绕已发布智课展开学习、提问和进度续接。

教师入口：课程建设 / 资源管理 学生入口：课程资源 / 移动学习页 结果回流：学情查看 / 节点热区 / 问答记录
流程核对建议
建议按这条线核对：教师从课程页进入工作台 → 解析课件并发布智课 → 学生通过课程直达链接学习并提问 → 系统回传学习进度和问答记录 → 教师查看学情。
教师端接入
👩‍🏫
在课程页中增加“智课工作台”入口，教师可从课程上下文直接进入项目模式，减少手动切换成本。
1课程平台携带课程上下文、教师身份与课程标识打开工作台。
2工作台自动绑定项目，进入“项目模式”，支持解析、生成、发布。
3发布后将智课资源回写为课程资源条目，并生成学生学习直达入口。
学生端接入
🎓
学生无需理解后台制作流程，只需从课程页或学习通看到“已发布智课”，即可进入对应课程学习。
1学生点击课程内的智课资源，进入带 `projectId` 的学习页。
2系统呈现当前项目、课程名称、学习节点，并支持中途提问。
3学习进度、提问记录、节点热区自动回传教师端学情页面。
平台侧协同
🧩
通过标准化开放接口和异步调用设计，将智课生成流程嵌入现有课程体系，而不是另起一套孤立系统。
1平台同步课程、用户与资源上下文。
2智课服务返回发布状态、学习链接、资源地址与学情统计。
3最终在课程平台形成“课程资源 + 学习行为 + 教师回看”的闭环。

教师 / 学生使用旅程

这部分用于说明系统如何融入课程流程。不是单独打开一个工具页面，而是把智课能力挂进教师建课、学生学课、教师看学情这三段教学动作中。

1
进入工作台
教师在课程页点击“智课工作台”，系统携带课程标识进入绑定项目模式。

2
生成并发布
完成课件解析、讲稿生成、问答配置和语音 / 数字人资源后，一键发布智课并生成学生学习链接。
项目模式 学生直达链接

学生学习与续接
学生从课程资源页直接进入学习页，围绕当前课程提问，并在回答后续接回讲解节点。
实时问答 进度续接
4
学情回看
教师返回学情页查看学习人数、节点热区、问答记录和续接行为，用于后续精准辅导。

课程 Web 端
  • 适合作为教师工作台入口，承载课件上传、讲稿生成与发布。
  • 支持通过课程上下文直接进入绑定项目模式。
  • 便于支持“从课程进入智课工作台”的企业场景适配。
移动学习端
  • 适合作为学生学习入口，直接打开已发布智课。
  • 学生只看课程、讲稿、音频、数字人和提问入口，交互更轻量。
  • 学习行为继续回流到教师学情页，形成闭环。
流程核对建议
  • 先确认“课程页进入工作台”，再检查教师端制作。
  • 发布后检查“复制学生学习链接”和学生直达学习页。
  • 最后切到学情查看页，确认学习数据回流。
