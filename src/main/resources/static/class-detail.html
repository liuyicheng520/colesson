发给本班上课

只有本班学生能看到

「发给本班上课」是什么意思？
就是把做好的课发给这个班的学生：他们打开班级就能学。别的班看不到，公开课程列表里也不会出现。
  1. 先在「本班课程」把课加入本班
  2. 在下面选中这门课，点「发给本班」
  3. 学生用邀请码进班后即可上课
